# 🌐 全球大豆贸易网络的脆弱性分析与关键节点免疫策略评估

> 基于复杂网络理论，构建 2024 年全球大豆**有向加权贸易网络**，从拓扑特征、节点中心性、SIR 传播动力学、网络鲁棒性四个维度，识别贸易体系中的关键国家并评估不同"免疫策略"的保障效率。
>
> 关键词：`复杂网络` `igraph` `中心性分析` `SIR 模型` `鲁棒性分析` `ggplot2` `Gephi`

---

## 一、项目背景 & 研究目的

大豆是全球重要的粮食安全战略物资，中国大豆进口量占全球贸易总量的 60% 以上。近年地缘冲突、极端天气与出口政策波动频繁冲击大豆供应链，**贸易网络是否稳定、风险从哪里爆发、保障资源该投向谁**，是值得量化回答的问题。

本项目将国家/地区抽象为节点、贸易流向抽象为有向边、贸易额抽象为边权重，重点回答三个问题：

1. **网络长什么样？** —— 计算拓扑特征与多维度中心性，识别核心国家；
2. **风险如何传导？** —— 用 SIR 模型模拟贸易冲击在网络中的扩散过程，对比"随机爆发"与"核心国家爆发"两种场景；
3. **结论是否稳健？** —— 设计随机故障与 4 种蓄意攻击（按度 / 介数 / 接近 / 特征向量中心性排序移除节点）共 5 种扰动策略，观察网络连通性的崩溃速度，检验"核心节点决定网络稳定性"这一基准结论在更换评价指标后是否依然成立。

## 四、分析流程

**步骤 1：数据预处理与网络构建**
读入邻接矩阵，经 `graph_from_adjacency_matrix()` 构建有向加权网络，并与边列表中的国家名称做匹配；鲁棒性实验中对矩阵做二值化处理（仅关注连通关系）。

**步骤 2：基准分析 —— 拓扑特征与中心性识别**
计算节点数、边数、平均路径长度、网络密度、平均度、聚类系数等整体指标；并从出/入度、加权度、介数、接近、特征向量 5 个维度对全部 175 个节点排序，识别出口核心、进口核心与中转枢纽。

**步骤 3：SIR 传播动力学模拟**
设置感染率 β = 0.3、恢复率 γ = 0.1、模拟 50 个时间步、初始感染节点 3 个，分别模拟：① 随机选取种子节点（对照组）；② 加权出度 Top3 出口国作为种子（核心节点组），记录感染峰值与传播曲线。

**步骤 4：鲁棒性检验（扰动实验）**
按 5 种策略分 20 个批次逐步移除节点，每步计算**最大连通子图相对大小（LCC Ratio）**，并汇总 R20、R50、R80、AUC 四项指标：

- `random` 随机移除（模拟局部小国随机中断）
- `degree` 按度中心性降序移除（蓄意攻击核心国）
- `betweenness` 按介数中心性降序移除（攻击中转枢纽）
- `closeness` 按接近中心性降序移除
- `eigenvector` 按特征向量中心性降序移除

**步骤 5：绘图输出**
使用 R base plot 输出 SIR 双联传播曲线，使用 ggplot2 输出五策略鲁棒性对比曲线与攻击前后网络结构六宫格图，另用 Gephi 生成网络拓扑主图。

## 五、核心结论 / 分析结果

### 1. 网络整体：稀疏、短路径、核心-边缘结构

| 指标 | 数值 | 解读 |
|---|---|---|
| 节点数 / 边数 | 175 / 约 500 | 贸易关系总体稀疏 |
| 网络密度 | 0.033 | 多数国家只与少数伙伴贸易 |
| 平均路径长度 | 2.68 | 平均 2~3 个中转环节即可通达，呈小世界特征，风险传导快 |
| 平均度 | 5.714 | 每国平均仅约 5~6 个贸易伙伴 |
| 模块化系数 / 社团数 | 0.149 / 5 | 存在一定区域贸易聚集 |

### 2. 核心节点：巴西、美国主导出口，中国主导进口

- **加权出度 Top3**：巴西（约 423 亿美元）、美国（约 240 亿美元）、阿根廷 —— 出口高度集中；
- **加权入度 Top1**：中国（约 468 亿美元），远超德国、日本、西班牙、韩国等国 —— 进口端高度依赖核心来源；
- 网络呈现典型的 **"核心-边缘"结构与无标度特征**，少数国家承载绝大多数贸易流量。

### 3. SIR 传播模拟：风险一旦爆发即快速蔓延

两组实验（各 3 个初始感染节点）感染峰值分别为 **127（随机组）与 120（核心节点组）**，50 个时间步内恢复节点均累计至 160+，表明在 β=0.3、γ=0.1 的参数下风险传导迅猛、波及范围广；两组结果接近也提示：**在连接稠密的网络中，仅靠"随机布防"无法抑制传播，有限的保障资源更应定向投放至核心节点**。

![SIR传播曲线对比](数据/图片/sirRplot.png)

### 4. 鲁棒性检验：耐随机故障，怕蓄意攻击 —— 结论高度稳健 ✅

| 移除策略 | R20 | R50 | AUC |
|---|---|---|---|
| 随机故障 random | **0.76** | **0.36** | **0.399** |
| 蓄意攻击·度 degree | 0.337 | 0.023 | 0.136 |
| 蓄意攻击·介数 betweenness | 0.360 | **0.011** | **0.132** |
| 蓄意攻击·接近 closeness | 0.423 | 0.069 | 0.172 |
| 蓄意攻击·特征向量 eigenvector | 0.480 | 0.074 | 0.187 |

- **随机移除 20% 节点时网络仍保留 76% 的连通性**（R20=0.76），移除一半仍保留 36%，整体韧性较强；
- **按介数中心性蓄意攻击时网络崩溃最快**：仅移除 50% 节点，LCC 相对大小仅剩 **0.011**；按度攻击也仅余 0.023；
- **稳健性判断**：更换度、介数、接近、特征向量 4 种核心节点识别口径，蓄意攻击的 R50 均远低于随机故障（最差也仅为 0.074 vs 0.36），"核心节点决定网络稳定性、网络对系统性冲击高度脆弱"这一基准结论**不随指标选择而改变，结果稳健**。

![不同攻击策略下最大连通子图变化曲线](数据/图片/鲁棒性Rplot1.png)

攻击前后的网络结构对比（移除前 20% 节点）也直观显示：随机故障后主体结构尚存，而四种蓄意攻击后网络均碎裂为大量孤立节点。

![攻击前后网络结构对比](数据/图片/鲁棒性Rplot.png)

**现实启示**：局部小国的贸易中断影响有限，而巴西、美国等核心出口国一旦遭遇自然灾害或出口管制，将造成全球贸易网络大面积瘫痪。对中国而言，应推进进口来源多元化、深化与核心出口国的长期合作、保障高介数中转通道畅通，并依托复杂网络模型搭建数字化供应链风险预警系统。
